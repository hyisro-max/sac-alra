# Stage 12 — extensibility

Read `../docs/DEVELOPER_MANUAL.md` from top to bottom. As a safe practice task,
copy a Tool to a temporary location, verify it has one public method, compile it,
and run the disconnected tests. Do not enable the copy.

The stage passes when a new maintainer can explain Tool installation, Knowledge
hygiene, DL worker wiring, Valves, testing, prompt promotion, versioning, and
rollback without reading the vendor source first.
